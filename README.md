## 1. 터미널 실습 기록

### 현재 위치 확인 (pwd)
- 사용한 명령어: `pwd`
- 실행 결과: `C:\WINDOWS\system32`
- 설명: 현재 작업 중인 폴더(디렉토리)의 위치를 확인하는 명령어
- # PowerShell 터미널 기초 실습
## 오늘 배운 명령어
| 명령어 | 설명 |
|--------|------|
| pwd | 현재 위치 확인 |
| cd ~ | 홈 폴더로 이동 |
| mkdir dev-workspace | 폴더 생성 |
| cd dev-workspace | 폴더 진입 |
| ls | 폴더 내용 확인 |
| New-Item hello.txt | 파일 생성 |
| Set-Content hello.txt "내용" | 파일에 내용 쓰기 |
| Get-Content hello.txt | 파일 내용 읽기 |
| Copy-Item hello.txt hello-copy.txt | 파일 복사 |
